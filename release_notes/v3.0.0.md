# hifi-wifi v3.0.0

**Official Release** • June 20, 2026

The official v3.0.0 release enables **WiFi roaming by default**, fixing the need to manually reactivate WiFi on the Steam Deck after waking from sleep or moving between access points.

This release consolidates all improvements from the `v3.0.0-rc1` testing cycle (including automatic sudo elevation) and introduces key stability, usability, and installer enhancements.

---

## What's Changed since RC1

* **WiFi Roaming ON by default**: Background scanning is enabled by default to ensure seamless roaming.
* **Command Renamed**: Simplified `scan-suppress` to `scan`:
  * `hifi-wifi scan on` / `off` / `status`
* **Traffic Control (`tc`) Safety**: Gracefully bypasses CAKE QoS if `tc` is missing, preventing log floods.
* **Homebrew Dependency Support**: `install.sh` now automatically installs and links `iproute2` (`tc`) for plug-and-play CAKE QoS on SteamOS and Bazzite.
* **Latency & Stability Tweaks**: Removed unstable NAPI configurations causing regressions and optimized scan suppression loops.
* **Simplified CLI**: Cleaned up deprecated options like `--force-performance`.

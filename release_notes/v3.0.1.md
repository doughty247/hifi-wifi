# hifi-wifi v3.0.1: The "Play Anywhere" Update

**Release** • June 22, 2026

This release introduces the **Fast Travel** background scanning governor, allowing seamless roaming and movement in multi-AP home networks without background scan latency spikes.

---

## Key Improvements

### Background Scanning & Roaming ("Fast Travel")
- **Tri-state Scan Suppression:** Configurable background scanning (`adaptive`, `on`, or `off`).
- **Signal-Aware Scanning:** Restricts scans to low-signal thresholds (e.g., below -72dBm on 5GHz) to prevent connection drops while moving.
- **Grace Periods & Overrides:** Permits scans for 30 seconds post-boot/wake, and disables them entirely during active gameplay.
- **CLI Control:** Added `hifi-wifi scan [adaptive|on|off]` commands for quick runtime switches.

### Identity & Network Overrides
- **Custom MAC Overrides:** Explicit `wifi_mac_address` support (`permanent`, `stable`, or custom MAC strings) written directly to NetworkManager configs.
- **Custom Hostname:** Added option to define and set a persistent system hostname at startup.

### Performance & Kernel Tweaks
- **Direct ASPM Control:** Disables PCIe ASPM directly via sysfs for stable hardware link performance under heavy loads.
- **Sysctl Adjustments:** Optimized `net.core.netdev_budget` and disabled `tcp_slow_start_after_idle` to prevent packet queuing lag.
- **Resilient IRQ Pinning:** Consolidates interrupt affinity handling and gracefully bypasses kernel-managed IRQ write warnings.
- **Robust Configuration:** Missing config settings now fall back to safe defaults instead of preventing daemon startup.

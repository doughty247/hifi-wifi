# hifi-wifi v3.0.0-rc1

**Release Candidate 1** • February 5, 2026

Major performance improvements for gaming and streaming on Steam Deck and handhelds.

---

## What's New

**Scan Suppression**
- Eliminates WiFi stuttering during gameplay
- Reduces latency spikes from 150ms to 3-5ms
- Automatically enabled when connected
- Turn off to allow WiFi roaming: `hifi-wifi scan-suppress off`

**Power Save Control**
- New commands to control WiFi power mode
- Settings persist across reboots and sleep
- `hifi-wifi power-save off` for maximum performance
- `hifi-wifi power-save adaptive` for automatic mode (default)

**Smarter Network Tuning**
- Automatically detects your network speed
- Optimizes bufferbloat settings based on your WiFi
- Adjusts when switching networks or connecting to VPN

**Steam Deck OLED Support**
- Fixed WiFi optimizations not applying on OLED model
- IRQ pinning now works correctly

**Easier to Use**
- No need to type `sudo` for most commands
- Automatically prompts for password when needed
- Fixes "command not found" errors (#15)

---

## Fixed

- Fixed WiFi stuttering caused by background scans
- Fixed network settings not updating when switching networks
- Fixed power save mode re-enabling after sleep
- Fixed commands requiring sudo not working when not in PATH (#15)

---

## Removed

- `--force-performance` flag (use `hifi-wifi power-save off` instead)

---

## Commands

| Command | What it does |
|---------|-------------|
| `hifi-wifi status` | Show current status |
| `hifi-wifi power-save off` | Maximum performance |
| `hifi-wifi scan-suppress on` | Stop WiFi stuttering (default) |
| `hifi-wifi on` / `off` | Turn service on or off |
| `hifi-wifi uninstall` | Remove completely |

Run `hifi-wifi --help` to see all commands.

---

## Upgrading

If you used `--force-performance` before, run this once:
```bash
hifi-wifi power-save off
```

Otherwise, just update and restart the service.

# hifi-wifi v3.1.0: The "Real CAKE" Update

**Release** • June 23, 2026

After three months of work since v3.0.0, v3.1.0 is finally ready. This release makes the entire hifi-wifi engine faster, more efficient, and fully adaptive. Instead of using static configurations, hifi-wifi now dynamically adjusts latency controls, background scanning, power profiles, and network settings based on what you are doing in real-time.

Here is what's new:
- **Zero-lag background downloads:** You can download games in the background without ruining your ping. The engine automatically detects when a game starts or stops, sets up a prioritized lane for your game traffic, and throttles background downloads only when active jitter is detected.
- **Seamless roaming:** Pauses background Wi-Fi scanning while gaming to prevent periodic ping spikes, but automatically resumes it if your signal drops, allowing your device to steer to a closer router smoothly.
- **Dynamic power saving:** Switches PCIe bus states, Wi-Fi power-save, and Ethernet energy modes on the fly. It forces power-saving when idle or on low battery, and instantly shifts to low-latency performance mode when plugged in or playing a game.
- **Reliable customization:** Hostname, MAC address overrides, and scan settings apply reliably at startup with safe, automated defaults.

## Technical Details

### 1. Dynamic QoS & Latency Control
Instead of static bandwidth caps, the engine now automatically scales your speed limits based on real-time network jitter and packet loss, loading and unloading shaping rules on the fly.
- **Dynamic Qdisc Swapping & Restoration:** The CAKE shaper is dynamically loaded only during active Game Mode. When you exit your game, the network stack is restored to a raw, unshaped state for maximum download speeds.
- **Graceful Cleanup on Shutdown:** Listens for both `SIGINT` (Ctrl+C) and `SIGTERM` (systemd stop/shutdown) signals. The shutdown hooks reliably tear down `ifb0` redirect redirection and explicitly restore the default `mq` root qdiscs on multi-queue network adapters.
- **IFB Ingress Redirection & Fallback:** Download traffic is redirected to a virtual Intermediate Functional Block (`ifb0`) for precise CAKE shaping. The initialization code checks if the `ifb` kernel module is loadable, falling back gracefully to raw egress shaping if the module is missing or blocked.
- **Dynamic Cgroup Discovery:** Scans the `/sys/fs/cgroup` tree at startup to dynamically map user cgroups, systemd application slices, and transient Flatpak scopes for any UID. This enables automatic DSCP `EF` tagging across standard desktop distributions (Fedora, Arch, Debian) rather than hardcoding SteamOS paths.
- **Multi-Queue Egress Shaping:** Queries active TX hardware queues, sets the root to `mq` (Multi-Queue) to preserve driver-level queue load balancing, and shapes queues individually.
- **cgroup v2 & DSCP tagging:** Automatically sets kernel priority (`meta priority set 6`) and DSCP Expedited Forwarding (`EF`) tags on detected application scopes. This is restricted to UDP traffic to prevent bulk TCP downloads from hijacking the voice queue.
- **Clean Teardown Rules:** Guarantees complete cleanup of firewall tables, virtual interfaces (`ifb0`), and traffic control rules upon exit or shutdown.

### 2. Core Engine & Active Telemetry
Built for zero overhead, this engine replaces periodic polling with kernel event subscriptions and active socket tracking to react instantly to network changes.
- **Active Socket RTT Telemetry:** Monitors TCP socket descriptors of games, launchers, and streams (Steam, Gamescope, Moonlight) directly in `/proc/<pid>/fd/` and queries the kernel's `TCP_INFO` struct.
- **Self-Healing Jitter Scaling:** Dynamically scales down the CAKE bandwidth ceiling by up to 30% during wireless jitter spikes or packet loss events, restoring full limits once the link stabilizes.
- **Event-Driven Architecture:** Replaced periodic polling with an asynchronous Netlink socket listener subscribing directly to kernel events (`RTMGRP_LINK`). Link state transitions, connections, and speed changes are detected instantly.
- **Dynamic IRQ Locking:** The Netlink socket listener automatically triggers a re-evaluation of sysfs IRQ paths upon link-up events, preserving hardware core affinity even if the network driver re-allocates MSI-X vectors.
- **Tokio Runtime Loop:** Reorganized the core daemon around an event-driven loop, dropping idle CPU utilization to near-zero (<0.1%).

### 3. Dynamic Power & Hardware Management
Toggles PCIe bus states, Wi-Fi power saving, and Ethernet energy modes based on active gameplay or power source, and overrides settings to force power-saving when your battery runs critical.
- **Dynamic PCIe ASPM & Runtime PM:** Shifts PCIe Active State Power Management (ASPM) control to the dynamic governor. Disables L-states (0ms wake latency) during Game Mode / AC power, but restores them to `auto` when idle on battery.
- **Asymmetric Hysteresis:** Entering performance mode (ASPM/power-save OFF) is now instant (1 tick/0ms delay) to eliminate latency immediately. Exiting performance mode (ASPM/power-save ON) is delayed by 10 seconds (5 ticks) to prevent hardware power state flapping during long game loading screens.
- **Critical Battery State Override:** Monitors battery capacity. When the battery drops below `critical_battery_pct` (default `15%`), it overrides game-mode settings to force Wi-Fi power save and EEE ON to extend runtime.
- **Kernel & Interrupt Tuning:** Optimizes `net.core.netdev_budget`, disables `tcp_slow_start_after_idle` to prevent latency after brief inactivity, and pins interrupt (IRQ) affinity for network adapters across CPU cores.
- **Hardened Capability Boundaries:** Systemd service execution is restricted strictly to `CAP_NET_ADMIN`, `CAP_NET_RAW`, and `CAP_SYS_ADMIN` capability bounds with `NoNewPrivileges=true` enabled, cryptographically preventing SUID privilege escalation in sub-tasks.
- **Input Sanitization & Bazzite Compatibility:** Implemented strict RFC 1123 hostname validation and standard MAC address checks on user-facing config overrides. Hostnames are capped at a maximum of 20 characters to prevent container DNS resolution issues under Bazzite's Distrobox integration. Any shell or parameter command injection vectors are sanitized and rejected at startup.
- **Robust Config Fallbacks:** Missing config keys now fall back to safe defaults automatically, ensuring the daemon starts successfully.

### 4. Adaptive Scanning & Roaming
Pauses background Wi-Fi scanning during gameplay to prevent lag spikes, but dynamically resumes scanning if your signal weakens, letting your device transition between access points smoothly.
- **Tri-State Scan Suppression:** Configurable background scanning (`adaptive`, `on`, or `off`). Under `adaptive`, background scanning is paused during Game Mode but resumes immediately on weak signals.
- **Active Handovers:** Monitors signal quality and triggers proactive NetworkManager BSSID association handovers to target access points when signal strength drops below `-80 dBm`.
- **CLI Scanning Controls:** Added simple commands (`hifi-wifi scan [adaptive|on|off]`) for quick, manual scan governor overrides at runtime.
- **MAC & Hostname Customization:** Enforces custom MAC address policies (`permanent`, `stable`, or custom MAC strings) and sets a persistent system hostname at startup.

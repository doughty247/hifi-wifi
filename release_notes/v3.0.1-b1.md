# hifi-wifi v3.0.1-b1

**Beta Release 1** • June 20, 2026

This beta release introduces support for custom MAC address and hostname overrides, allowing users to stabilize local network identity, bypass default MAC randomization, and resolve the system easily on local networks.

---

## Key Improvements

### 1. MAC Address Customization (Issue #22)
* **Bypass Randomization**: Restores the ability to disable NetworkManager's default per-connection MAC randomization.
* **Flexible Modes**: Added `wifi_mac_address` configuration under `[wifi]`, supporting:
  * `"permanent"`: Enforces the factory hardware MAC address.
  * `"stable"`: Generates a stable, hashed random MAC address per SSID.
  * `"XX:XX:XX:XX:XX:XX"`: Enforces a specific user-defined MAC address.
* **Persistent Configuration**: Writes global overrides to `/etc/NetworkManager/conf.d/99-hifi-wifi-mac.conf` which survive updates, reboots, and sleep cycles.

### 2. Custom Hostname & Local DNS Override
* **Simple Resolution**: Added `hostname` configuration under `[system]`.
* **Zero-Configuration Resolution**: Allows you to force a custom hostname (e.g. `steamdeck`) so your router resolves the device as `steamdeck.lan` or `steamdeck.local` automatically.
* **Automatic Verification**: The daemon checks the current hostname on startup and updates it dynamically via `hostnamectl` if different.

### 3. Resilient Configuration Loading
* **Flexible Parsing**: Added `#[serde(default)]` container attributes to `WifiConfig` and `SystemConfig`.
* **Backward Compatibility**: Any omitted parameters default gracefully, preventing daemon startup failures on minimal config files.

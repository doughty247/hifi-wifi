# hifi-wifi v3.0.1-b1

**Beta Release 1** • June 20, 2026

This beta release introduces support for custom MAC address and hostname overrides, allowing users to stabilize local network identity, bypass default MAC randomization, and resolve the system easily on local networks.

---

## Key Improvements

### Connection Identity & DHCP
* **MAC Address Override**: Added a `wifi_mac_address` configuration field under `[wifi]`, supporting `"permanent"` (factory MAC/disable randomization), `"stable"` (stable hash per SSID), or an explicit user-defined MAC address.
* **Persistent MAC Overrides**: Writes global overrides directly to `/etc/NetworkManager/conf.d/99-hifi-wifi-mac.conf` to persist across sleep/wake cycles.
* **Custom Hostname Support**: Added a `hostname` configuration field under `[system]`. The daemon automatically verifies and enforces the system hostname using `hostnamectl` at startup.

### PCIe & Link Power
* **Direct PCIe ASPM Override**: The system optimizer now directly overrides sysfs link nodes (`l0s_aspm`, `l1_aspm`, etc.) to disable ASPM, and sets runtime power management to `on` when `driver_tweaks_enabled` is active. This ensures the Wi-Fi card does not enter unstable low-power states even if the BIOS ignores modprobe options.

### TCP & Network Device Latency
* **TCP Slow Start Inhibition**: Added `net.ipv4.tcp_slow_start_after_idle = 0` to sysctl tuning. This prevents TCP from throttling its congestion window after brief pauses, ensuring zero-latency ramp-up for game streaming controller inputs.
* **NAPI Packet Budgets**: Tuned kernel network device budget limits (`net.core.netdev_budget = 600`, `net.core.netdev_budget_usecs = 8000`) for high packet-rate efficiency.

### Configuration Engine
* **Resilient Parsing**: Added `#[serde(default)]` container attributes to `WifiConfig` and `SystemConfig`. Any omitted parameters now default gracefully instead of failing to start the daemon.

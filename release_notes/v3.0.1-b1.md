# hifi-wifi v3.0.1-b1: The "Fast Travel" Update

**Beta Release 1** • June 20, 2026

This release focuses on freedom of movement. A new smart, adaptive background scanning governor (nicknamed "Fast Travel") allows walking around the house while streaming Moonlight or playing an MMO without getting hit by periodic 170ms ping spikes. Custom MAC address and hostname overrides stabilize local network identity, bypass default MAC randomization, and resolve system issues on local networks.

---

## Key Improvements

### Background Scanning & Roaming
- Replaced the static `scan_suppress` boolean config with a tri-state setting supporting `"adaptive"` (default), `"on"`, or `"off"`.
- Added sleep/wake/boot grace period: Scanning is allowed for 30 seconds after startup or resume from suspend to accelerate connection setup.
- Implemented signal-aware scans: When in `"adaptive"` mode, scans are only allowed if the active AP signal falls below the band usability threshold (e.g. -72dBm on 5GHz). Scans are suppressed when connection signal is strong.
- Game mode scan override: Scanning is always suppressed when gaming traffic is detected (based on PPS rate), overriding the signal strength rule to guarantee low latency.
- Extended the `hifi-wifi scan` CLI command to support `scan adaptive`, `scan on`, and `scan off`.

### Connection Identity & Network Overrides
- Added `wifi_mac_address` config under `[wifi]`. Supports `"permanent"`, `"stable"`, or custom hexadecimal MAC string.
- Writes global overrides directly to `/etc/NetworkManager/conf.d/99-hifi-wifi-mac.conf` to persist changes across OS updates.
- Added `hostname` config under `[system]` to set system hostname via `hostnamectl` at startup.

### Kernel & Device Optimizations
- Direct PCIe ASPM override: System optimizer now disables ASPM directly by writing `0` to sysfs PCI device nodes (`l0s_aspm`, `l1_aspm`, etc.) and sets runtime power management to `on`.
- Added `net.ipv4.tcp_slow_start_after_idle = 0` to sysctl to prevent TCP congestion window throttling after pauses in streaming.
- Tuned `net.core.netdev_budget` to `600` and `net.core.netdev_budget_usecs` to `8000` to handle high-packet-rate gaming streams efficiently.

### Configuration Engine
- Added `#[serde(default)]` to `WifiConfig` and `SystemConfig` structs so missing config items default gracefully rather than failing daemon startup.
